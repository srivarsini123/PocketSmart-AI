
# Phase 7 - Project Documentation

## Project Name
PocketSmart AI - Your Smart Budget and Recommendation Assistant

## 1. Project Overview

PocketSmart AI is an AI-powered budgeting and recommendation
assistant designed to help users understand their income,
expenses and remaining budget.

## 2. Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Google Gemini API
- SQLite

## 3. Working

1. User enters monthly income.
2. User enters expense details.
3. The system calculates total expenses.
4. The system calculates remaining balance.
5. Spending information is analyzed.
6. Gemini AI generates budget suggestions.
7. Recommendations are displayed to the user.

## 4. Benefits

- Easy expense tracking
- Simple budget calculation
- Spending analysis
- AI-powered suggestions
- Easy-to-use interface

## 5. Future Enhancements

- Expense charts and graphs
- Voice input
- Multiple language support
- Monthly spending reports
- More personalized recommendations

## 6. Conclusion

PocketSmart AI provides a simple and interactive way for users
to understand their budget and receive AI-based recommendations.
