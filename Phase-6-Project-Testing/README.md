# Phase 6 - Project Testing

## Project Name
PocketSmart AI - Your Smart Budget and Recommendation Assistant

## 1. Testing Objectives

The application is tested to verify that budget calculations,
expense analysis and AI recommendations work correctly.

## 2. Test Cases

| Test Case | Input | Expected Result |
|---|---|---|
| 1 | Monthly income | Income should be displayed |
| 2 | Multiple expenses | Total expense should be calculated |
| 3 | Income greater than expenses | Remaining balance should be calculated |
| 4 | Empty input | User should be asked to enter required information |
| 5 | AI recommendation request | AI should provide a useful response |
| 6 | Clear button | Input and results should be cleared |

## 3. Testing Process

The application will be tested locally using the Flask development
server. Different income, expense and recommendation inputs will
be used to verify the application behaviour.

## 4. Testing Result

The main features of the PocketSmart AI application will be checked
to ensure that the system works as expected.

## 5. Conclusion

Testing helps identify errors and ensures that the application
provides a simple and reliable user experience.
