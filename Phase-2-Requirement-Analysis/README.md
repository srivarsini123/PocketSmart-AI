# Phase 2 - Requirement Analysis

## Project Name
PocketSmart AI - Your Smart Budget and Recommendation Assistant

## 1. Functional Requirements

- The user can enter monthly income.
- The user can enter expenses.
- The user can categorize expenses.
- The system can calculate total expenses.
- The system can calculate remaining balance.
- The system can analyze spending.
- The system can generate AI-based budget suggestions.
- The system can provide recommendations based on user inputs.

## 2. Software Requirements

- Python
- Flask
- HTML
- CSS
- JavaScript
- Google Gemini API
- SQLite
- Visual Studio Code
- GitHub

## 3. Hardware Requirements

- Computer or Laptop
- Internet Connection
- Minimum 4 GB RAM

## 4. Users

The system is designed for students, working professionals
and individuals who want to manage their personal budget.

## 5. Expected Requirements

The application should provide a simple interface for entering
financial information and should generate understandable
budget analysis and recommendations.
