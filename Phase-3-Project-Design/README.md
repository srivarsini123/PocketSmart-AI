# Phase 3 - Project Design

## Project Name
PocketSmart AI - Your Smart Budget and Recommendation Assistant

## 1. System Architecture

User
  ↓
PocketSmart AI Web Interface
  ↓
Flask Backend
  ↓
Budget Calculation & Expense Analysis
  ↓
Google Gemini API
  ↓
AI Suggestions and Recommendations
  ↓
Web Interface
  ↓
User

## 2. Working Process

1. The user opens the PocketSmart AI application.
2. The user enters monthly income.
3. The user enters expense details.
4. The system calculates total expenses.
5. The system calculates the remaining balance.
6. The system analyzes the spending information.
7. Gemini AI generates useful budget suggestions.
8. The suggestions are displayed to the user.

## 3. User Interface Design

The application will contain:

- Project title
- Monthly income input
- Expense input
- Expense category
- Calculate button
- Budget summary
- AI recommendation section
- Clear/reset option

## 4. Design Goal

The interface is designed to be simple, clean and easy to use.
